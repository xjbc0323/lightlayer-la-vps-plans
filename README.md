## 美西 VPS 的坑，都出在回程

买美西 VPS 踩坑的过程高度雷同：套餐页写着"美西直连"，刚开机 ping 一下 150ms 挺满意，几天后晚上八九点再测，延迟飙到 600ms。原因是回程走了普通公网，晚高峰三大运营商国际出口一起堵。

判断一台美西机器值不值，看的不是机房在哪，是回程走哪条线。

- **CN2 GIA（AS4809）**：中国电信的高端出海线路，全程独立高优先级通道。识别方法很直接，traceroute 结果里出现 `59.43.x.x` 的节点，就是走了 CN2 GIA。电信用户晚高峰体感差别最大。
- **CMIN2（AS58807）**：中国移动对标 CN2 GIA 的产品，独立出海通道，QoS 优先级高于普通 CMI。2025 到 2026 年覆盖节点明显增多，价格通常比 CN2 GIA 低一些。
- **普通直连（CN2 GT / 163 骨干 / 各类 Tier 1 转接）**：走公共互联网，晚高峰容易拥堵。建站、跑 API、挂后台任务够用，对延迟敏感的场景不合适。

匹配规则很粗暴：家里装电信宽带的优先看 CN2 GIA，移动宽带优先看 CMIN2，联通宽带两条都能用，预算紧张就选普通直连并接受晚高峰的波动。

### LightLayer 的三条线路怎么对应

LightLayer 把洛杉矶的网络分成三档，名字上没有直接写 CN2 或 CMIN2，需要对照着看：

**Premium 优化线路**对应上面的高端档。官方口径把这条线描述为包含 CN2、CT、CU、CMI、PCCW、COGENT 的优化带宽，中国大陆访问延迟最低可到 50–80ms，跨境连接约 100ms 左右。这个数字是商家宣称，实际取决于你所在省份和运营商。第三方在 2024 年 5 月对洛杉矶优化线路的测试记录显示，去程三网直连到西海岸自家节点后接 Cogent 进机房，回程统一走移动 CMIN2（AS58807）回国。也就是说移动宽带用户走优化线路的收益最直接。

**Standard 标准线路**是三网直连的普通回国路径，官方给的延迟区间是 80–150ms。它比国际线路快，但没有 CN2 或 CMIN2 那种独立通道待遇。

**Global 国际线路**就是普通的国际带宽，端口大、价格低，适合面向海外用户或纯粹要大带宽下载的场景。用它做回国加速是选错了产品。

下单前建议自己验一遍：拿测试 IP 128.241.231.254 做 ping 和 traceroute，看回程落在哪个 ASN。花三分钟，能省掉一次退款扯皮。
